# disclosures

Public privacy policies and terms of use for shipped apps.

Hosted via GitHub Pages. Each app lives in its own subfolder:

- `bibleblitz/` — Bible Blitz

## Adding a new app

1. Create `<app-slug>/privacy.html` and `<app-slug>/terms.html`
2. Add the app to `index.html`
3. Commit + push to `main` — GitHub Pages redeploys automatically

Use the existing `bibleblitz/` files as a template.
